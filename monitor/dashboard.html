PlayLimit Monitor — setup

Reads the private logs repo directly in your browser. Nothing is sent anywhere except GitHub. The token is stored only in this browser's localStorage.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Resource owner: the repo owner · Repository access: Only the logs repo
  3. Permissions: Contents → Read-only · set an expiry you'll rotate
